# `taxipatch`

[![GitHub Release](https://img.shields.io/github/v/release/stashymane/taxipatch?include_prereleases)][GitHub Releases]

Patch for Crazy Taxi 3. Successor to CT3Tweaks.

> [!WARNING]
> Until the `1.0` release of this patch, you may encounter some bugs, and configuration options may change over time.
Sorry in advance :)

## Requirements

Only tested with the Fairlight & Xplosiv `CT3.exe` executables. Others will refuse to start for now.

## Installation

> [!NOTE]
> If you have used CT3Tweaks before on your game, make sure to remove the patched version and restore the backup (rename
> it to `CT3.exe` instead). CT3Tweaks modifies the original game file, which may be incompatible with this patch.

1. Get [Ultimate ASI Loader] (dinput8.dll version)  
   and place it in the same folder as `CT3.exe`
2. Get `taxipatch`:
    * Release version from [GitHub Releases] (`taxipatch.asi` under `Assets`)
    * Development version from [GitHub Actions][GitHub Actions runs]
    * or build it yourself
3. Next to `CT3.exe`, create a `plugins` folder and put `taxipatch.asi` inside
4. Start game

After the game runs with the patch installed for the first time, the default configuration file will be generated.  
If you want to adjust anything, you can do so there.

## Patches

* Screen resolution
* 60FPS mode
* Borderless & windowed mode
* FOV & correct aspect ratio
* Skips intro logos
* Fixes various game bugs

## Configuration

A configuration file `taxipatch.ini` is generated by the patch if one does not already exist. Values that are commented
out with `#` or `;` can be omitted and are configured by default.
